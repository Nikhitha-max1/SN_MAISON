# SN MAISON — Fashion Boutique Website

An AJIO-inspired multi-page fashion storefront for SN MAISON, built as a clean independent design (not a copy of AJIO branding).

## Pages
Home, Shop, New In, Collections, Lookbook, About, Journal, Product Details, Shopping Bag, Checkout, Contact, Account, Search, Shipping & Returns.

## Features
- Responsive desktop/mobile layout
- Product filters and sorting
- Product detail pages with URL product IDs
- Add-to-bag and remove-from-bag
- Persistent shopping bag using browser localStorage
- Search page and shop search
- Demo checkout/contact/account interactions
- Your supplied designer image is used as the SN MAISON studio hero/about image

## Run
Open `index.html` in a browser. No server or build step is required.

## Local fashion assets
The supplied photos are organized into `assets/Dresses`, `assets/Tops`, `assets/Bottoms`, and `assets/Outerwear`.
The product catalog in `script.js` now uses these local assets, so Shop filters and Product Details use the photos supplied with this project instead of the previous Unsplash product images.
